# Security reporting

Report suspected vulnerabilities privately to **lewis@canetoad.ai**. Include the affected package version, a minimal reproduction, the potential impact, and relevant runtime details. Do not include credentials or private datasets.

GitHub private vulnerability reporting is enabled for [toadai/grauss-kruger](https://github.com/toadai/grauss-kruger/security/advisories/new). You may use that private reporting form instead; email is the alternative if the form is unavailable to you. Do not disclose an unpatched vulnerability in a public issue or pull request.

For numerical correctness problems that are not security-sensitive, use the repository's normal contribution channel when accessible. State the input datum, projection parameters, expected result and authoritative reference; a forward/inverse round trip alone does not establish accuracy.

This project does not promise a response deadline or a supported-version security maintenance window. Check the changelog and npm releases for available fixes.
